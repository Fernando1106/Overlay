# 🎮 Multistream Overlay – by SOLVEXBOT

## 🚀 ¿Qué es esto?

Este es un **overlay multistream todo en uno**, diseñado para streamers que transmiten simultáneamente en **Twitch, Kick, YouTube y TikTok**. Muestra eventos en tiempo real, metas por plataforma, carrusel personalizable y un panel de control visual — todo desde el navegador, sin tocar código.

Funciona como un servidor local que puedes capturar en OBS como **fuente de navegador**, con una interfaz limpia y completamente configurable.

---

## 🛠️ ¿Cómo se usa?

1. **Descarga el ejecutable** desde la sección de [Releases](#).
2. **Ejecuta el archivo `.exe`**. El servidor arrancará automáticamente.
3. Abre el **panel de control** en tu navegador: `http://localhost:3500`
4. Configura tus canales, metas y apariencia desde el dashboard.
5. En **OBS**, agrega una **fuente de navegador** con la URL del overlay.
6. ¡Empieza tu stream y deja que el overlay haga su magia!

---

## 🧩 Características principales

- 📡 **Eventos en tiempo real** de Twitch, Kick, YouTube y TikTok — subs, bits, follows y Super Chats.
- 🏷️ **Badges por plataforma** con colores identificativos por tipo de evento.
- 🎯 **Contadores de metas individuales** por canal, configurables desde el dashboard.
- 🖼️ **Carrusel personalizable** con tus imágenes o banners.
- 🔔 **Últimos eventos destacados** en pantalla (último sub, último follow, etc.).
- 🎨 **Preview en vivo** de fuente, tamaño y apariencia antes de guardar.
- ⚙️ **Panel de control visual** con configuración guardable en un clic.
- 💾 **Persistencia de configuración**, incluso si reinicias el servidor.

---

## 🧠 Preguntas frecuentes

### ¿Funciona con OBS?
Sí. Agrega el overlay como **fuente de navegador** en OBS usando la URL local que genera el servidor.

### ¿Necesito configurar las 4 plataformas?
No. Puedes activar solo las plataformas que uses. Cada una se puede encender o apagar desde el dashboard.

### ¿Puedo personalizar las metas?
Sí. Desde el panel puedes establecer la meta de subs, seguidores o lo que necesites para cada plataforma de forma independiente.

### ¿Funciona en Windows?
Sí, el ejecutable está pensado para Windows. El servidor corre en local y no necesitas instalar nada más.
